Build: copy social.sh, social_layers.py and music.py next to ../preview/source/take1.mov and take-zh.mov, then run
  bash social.sh en elapsa-social-en.mp4
  bash social.sh zh elapsa-xiaohongshu-zh.mp4
The music is original (music.py writes it note by note), so it can be used anywhere.
Piano version: after social.sh, run
  bash piano.sh en elapsa-social-en-piano.mp4
  bash piano.sh zh elapsa-xiaohongshu-zh-piano.mp4
The piano is Bach's Prelude in C (WTC I), played by LJ's piano teacher (/Volumes/APPS/story/music/fast 2-44.mp3), used with permission.
